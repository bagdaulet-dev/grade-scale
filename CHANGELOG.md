# Changelog

## 0.1.0

- Course and assessment REST endpoints with MySQL/JdbcTemplate persistence.
- Decimal weighted grades and explicit provisional results below 100% weight.
- Eleven letter bands: A at 95, A- at 90, B+ at 85, then five-point intervals.
- Required-score planning for remaining course weight.
- Session ownership, CSRF, bounded input and transaction-safe weight updates.
- Resource-limited native preview, Docker Compose and persistent MySQL sessions.
- Responsive course workspace, grade dial, local fonts and browser tests.
- TestNG checks and GitHub Actions for verification and container delivery.
